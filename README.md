## Programming Language

The class will involve hands-on implementation and analysis of machine learning methods. There is no specific recommended programming language. However, coding examples and class lectures will focus on **Julia and Python**. Other good alternatives are MATLAB, R, and Octave. You should be able to code in a scripting language such as Python, R, or Julia.

## Prerequisites

Students need to be able to code in a scripting language, such as Python, R, or Julia. Ideally, students will have completed a basic probability course. Basic programming skills and some familiarity with statistics and calculus are expected.
